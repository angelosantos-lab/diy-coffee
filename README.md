# DIY Coffee: Do It Yourself!

An interactive, mobile-responsive front-end e-commerce website inspired by viral convenience-store café drink hacks across the Philippines. 

## Live Links
* **Live Website (GitHub Pages):** `https://[angelosantos-lab].github.io/diy-coffee/`
* **Public Repository:** `https://github.com[angelosantos-lab]/diy-coffee`

---

## Project Purpose
**DIY Coffee** helps Filipino students and budget-conscious coffee lovers discover, customize, and calculate costs for affordable café-style iced drinks (₱49–₱70) made from everyday convenience-store ingredients (7-Eleven, Kopiko, Nescafé, Milo, and Oatside).

---

## Pages & Features
1. **Homepage (`index.html`):**
   * Sticky navigation bar, full-width coffee bean hero banner, collaborated brand highlights, featured "All-Time Faves" drink cards, and business overview.
2. **Product Catalog (`Drink Catalog.html`):**
   * Responsive 5-column product grid showcasing full uncropped drink cups, prices, and descriptions.
   * **JavaScript Live Search & Category Filter:** Filter drinks by *All*, *Coffee-Based*, *Non-Coffee*, or *Floats*, or search recipes in real time.
   * **JavaScript Interactive Cart:** Add drinks, adjust quantities, remove items, calculate totals in `₱`, and trigger a simulated checkout confirmation.
3. **About Us (`About Us.html`):**
   * Brand story, core values, 3-step visual preparation guide, and team credits.
   * **JavaScript DIY Savings Calculator:** Interactive range slider calculating monthly peso savings when switching from ₱175 café drinks to ₱60 DIY Coffee drinks.

## Local Setup Instructions
1. Clone or download this repository to your computer:
   ```bash
   git clone https://github.com[angelosantos-lab]/diy-coffee.git
   ```
2. Open the `diy-coffee` folder in **Visual Studio Code**.
3. Open `index.html` in any modern web browser (or right-click `index.html` and select **Open with Live Server**).
